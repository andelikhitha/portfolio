# Full Stack Personal Portfolio Website

## Project Description
This is a Full Stack Personal Portfolio Website developed using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

The website showcases:
- Skills
- Projects
- Resume
- Contact Form

The contact form stores user messages in MySQL database using backend APIs.

---

## Features

- Responsive Design
- Interactive UI
- Typing Animation
- Contact Form Integration
- Backend API
- MySQL Database Connection
- Resume Download/View Option
